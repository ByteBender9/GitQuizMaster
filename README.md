# 🚀 GitMaster

An interactive Git learning platform that helps beginners master Git through structured lessons, visual roadmaps, and engaging quizzes. Built with modern web technologies, GitMaster provides a responsive and user-friendly experience for learning version control.

## ✨ Features

- 📚 Interactive Git learning modules
- 🛣️ Beginner-friendly Git roadmap
- 🧠 Multiple quiz categories
- 🎯 Difficulty levels (Easy, Medium, Hard)
- ⏱️ Quiz timer and score tracking
- 📊 Progress tracking
- 🌙 Dark & Light mode
- 📱 Fully responsive design
- 💾 LocalStorage support
- ✨ Smooth animations and modern UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Google Fonts

2. Open the project folder.

3. Open `index.html` in your browser.
